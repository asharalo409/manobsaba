# manobsaba
# মানবসেবা ফাউন্ডেশন ওয়েবসাইট

React + Vite + Tailwind + Supabase। কোড: GitHub, হোস্টিং: Vercel।

## Vercel-এ দিতে হবে (Environment Variables)
- VITE_SUPABASE_URL = Supabase Project URL
- VITE_SUPABASE_ANON_KEY = Supabase anon public key

## অ্যাডমিন লগইন
Supabase > Authentication > Users > Add user (ইমেইল ও পাসওয়ার্ড)।
সাইন-আপ বন্ধ রাখুন: Authentication > Sign In / Providers > Email > Allow new users to sign up বন্ধ।

## জরুরি
- অনুদান সিস্টেম নিজে টাকা আদায় করে না। দাতা TrxID দেন, অ্যাডমিন যাচাই করেন।
- রক্তদাতার ফোন নম্বর ও চ্যাট সবার জন্য খোলা।
